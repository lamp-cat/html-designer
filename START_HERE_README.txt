HTML Designer 快速启动

macOS：
1. 双击 start-mac.command
2. 浏览器会打开 http://localhost:4175/
3. 关闭启动终端即可停止服务

Windows：
1. 双击 start-windows.bat
2. 浏览器会打开 http://localhost:4175/
3. 关闭命令行窗口即可停止服务

要求：Node.js 18 或更高版本。

命令行启动：
npm start

默认命令行地址：http://localhost:4173/

AI Design 需要本机已安装并登录 Codex CLI 或 Claude Code CLI。
