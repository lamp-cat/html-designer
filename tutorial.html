BEFORE YOU START

使用前，确认这三件事

普通编辑只需要本地服务。只有 AI Design 需要额外安装并登录本机 CLI。

01 启动本地应用

macOS 双击 start-mac.command，Windows 双击 start-windows.bat；也可以在项目目录运行 npm start。

02 优先使用桌面浏览器

Chrome、Edge、Arc 等 Chromium 浏览器可以建立文件写入连接，把修改直接保存回原 HTML。

03 按需准备 AI Design

需要 AI 协作时，确保 Codex CLI 或 Claude Code CLI 已安装并完成登录；普通画布编辑不依赖 CLI。

01

START A PROJECT

选择一种开始方式

打开应用后，先根据文件来源选择入口。已有本地文件时，优先使用“打开本地文件”。

怎么选
  • 打开本地文件：建立可写连接，后续“保存”会写回原文件。
  • 导入 HTML：读取一个文件，但不保留写入连接；完成后下载副本。
  • 新建设计：载入一份独立示例页面，适合快速体验。
  • AI Design：新建页面并同时打开 AI 设计面板。
建议需要持续修改同一个本地文件时，请使用“打开本地文件”，不要使用“导入 HTML”。
下一步：认识工作区域 ↓
02

KNOW THE WORKSPACE

认识三栏编辑工作区

进入设计器后，左侧负责找组件，中间显示完整 HTML，右侧负责精确调整当前组件。

三个区域
  1. 左侧：基础控件、页面结构和自定义控件。
  2. 中间：完整页面画布及缩放控制。
  3. 右侧：样式、属性、交互和当前元素 HTML。
画布比例完整页面画板默认按原设备宽度渲染，再整体缩放到工作区，不会为了适应窗口而改动页面内部布局。
下一步：选择并编辑组件 ↓
03

SELECT & EDIT

点击页面中的组件

在“编辑”模式点击文字、按钮、图片、区块或表格，设计器会识别组件并打开上拉操作菜单。

选中后可以
  • 双击文字，或点击菜单中的编辑按钮修改内容。
  • 上移、下移、选择父元素、复制或删除。
  • 拖动蓝色边框的控制点调整宽度和高度。
如果点不中确认顶部当前是“编辑”，而不是“浏览”；也可以在左侧“结构”树中选择对应节点。
下一步：像 PPT 一样自由拖动 ↓
04

FREE POSITION

把组件拖到任意位置

选择组件后点击“自由拖动组件”，再直接拖动蓝色选择框。组件不必局限在原有 DOM 排列位置。

操作方法
  1. 在上拉菜单点击六点拖动图标。
  2. 按住选中组件并拖到目标位置。
  3. 按住 Shift 可锁定水平或垂直方向。
  4. 在右侧输入 X、Y 精确位置，或点击“位置归零”。
结构与位置自由拖动改变视觉偏移；如果要改变 DOM 层级，请在左侧“结构”面板中拖动节点。
下一步：新增页面组件 ↓
05

BUILD COMPONENTS

用基础控件制作自定义组合

左侧只提供标题、容器、按钮、输入框、图片等基础 HTML 控件；需要的业务结构由你自由组合。

制作组合控件
  1. 点击基础控件或右侧的 + 插入；也可以拖进画布精确放置。
  2. 按住 Shift、Ctrl 或 ⌘，依次点击需要组合的控件。
  3. 在画布底部点击“创建组合控件”，输入名称。
  4. 以后从左侧“自定义”中点击 +、双击或拖动即可重复使用。
选择范围如果同时选中父控件和内部子控件，组合时只保留最外层控件，避免内容重复。
下一步：用检查器精确调整 ↓
06

INSPECT & STYLE

在右侧精确调整组件

选中组件后，右侧四个面板会直接修改当前元素，画布和源码会同步更新。

四个面板
  • 样式：字体、布局、间距、颜色、边框、阴影和自由位置。
  • 属性：标签、ID、class 和任意 HTML 属性。
  • 交互：配置点击、输入、提交等内联事件。
  • HTML：查看或替换当前组件的完整 HTML。
测试交互编辑画布不会执行页面脚本。添加交互后，切换到“浏览”模式进行实际测试。
下一步：直接编辑完整源码 ↓
07

EDIT SOURCE

直接修改完整 HTML 源码

顶部切换到“源码”，可以一次编辑完整文档，包括结构、样式和脚本。

使用方式
  1. 点击顶部“源码”。
  2. 在编辑区修改完整 HTML。
  3. 切回“编辑”或“浏览”，设计器重新解析并应用内容。
注意切换模式前请保持完整、合法的 HTML 结构。解析失败时先在源码中修正标签，再重新切换。
下一步：浏览并测试页面 ↓
08

BROWSE & TEST

浏览完整页面并测试交互

切换到“浏览”后，点击按钮、链接和表单会像普通网页一样工作，不再触发组件选择菜单。

浏览控制
  • 左下角依次是缩小、当前比例、放大、适应视口和完整页面画板。
  • 点击当前百分比可恢复到 100%。
  • 按 P 进入沉浸浏览，只保留页面、缩放和退出按钮。
  • 使用桌面、平板、手机按钮检查不同设备宽度。
切回编辑设计器会保留当前页面位置、滚动状态和已打开的页面弹窗，便于继续编辑正在查看的内容。
下一步：使用 AI Design ↓
09

LOCAL AI WORKFLOW

让 AI Design 修改页面

AI Design 通过本地服务连接 Codex CLI 或 Claude Code CLI。面板打开时，完整页面会继续显示在右侧。

第一次使用
  1. 点击顶部“AI Design”，展开“连接设置”。
  2. 选择 CLI；模型列表会自动读取该 CLI 当前支持的模型。
  3. 测试连接并保存设置。
  4. 描述希望生成或修改的内容，然后发送。
  5. 检查生成结果，确认后再应用到当前页面。
连接失败先在系统终端确认对应 CLI 可以正常运行并已登录，再回到“连接设置”刷新模型并重新测试。
下一步：保存与导出 ↓
10

SAVE & DELIVER

保存文件或导出副本

完成编辑后使用右上角的文件工具。保存行为取决于你在第 1 步选择的文件打开方式。

保存规则
  • 打开本地文件：“保存”直接写回原文件；磁盘内容被外部修改时会先提醒。
  • 导入或新建：“保存”和“导出副本”都会下载一个 HTML 文件。
  • 快捷键：Ctrl/⌘ + S 执行保存或下载。
不要混淆自动保存只用于恢复浏览器会话，不等于写回磁盘。交付前仍需点击“保存”或“导出副本”。
